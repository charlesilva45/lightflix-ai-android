# Lightflix AI 0.1

Aplicativo Android experimental para selecionar fotos, ajustar iluminação e contraste, visualizar e salvar cópias. Não inclui ainda IA avançada nem monitoramento automático da galeria.

## Build

Projeto Gradle Android. GitHub Actions executa `gradle assembleDebug` e publica o APK como artefato após compilação bem-sucedida.

## Privacidade

As imagens são processadas localmente. Não há upload de fotos ou conexão com serviços externos nesta versão.
